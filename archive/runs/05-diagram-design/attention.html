一句话里，谁在看谁

模型读「垫子」的时候，真正在看的不是这个词本身，而是「谁把它弄到这儿来的」。 每一个词都会给全句其他词打一遍相关性分数——分数高的，信息才流得过来。

三个角色
Query / Key / Value
Query 是「我想找什么」，Key 是「我有什么」，Value 是「找到了给你什么」。
为什么有效
距离不再是障碍
句子再长，相关的两个词都能直接连上，不必一步步传过去。
代价
长度平方的增长
每个词都要和所有词比一遍，句长翻倍，计算量翻四倍。
