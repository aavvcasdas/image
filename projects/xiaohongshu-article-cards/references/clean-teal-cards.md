# 干净青绿信息卡

仅当用户选择干净青绿、干净薄荷绿、清爽青绿卡片、干净信息卡，或明确要求「风格干净 / 浅绿强调 / 柔和圆角白卡」时使用本参考。本文件只定义视觉系统，不决定文章必须采用哪种信息结构。

## 视觉定位

- 浅灰暖白纸面（`#f7f7f5`），不是纯白海报，也不是奶油纸。
- 近黑正文 + **一种青绿强调色**（`#1f6b5a`）；星标、字段标签、徽章、标题关键词同色。
- 主体信息放在圆角白卡里，细灰描边、极轻阴影；模块之间靠对齐与间距，不靠重装饰。
- 允许极克制的青绿/灰色径向淡晕；禁止高饱和渐变、玻璃拟态、霓虹描边、大面积插画。
- 适合：开源项目清单、资料合集、对比条目、学习路径、产品要点卡。

## 画布与网格

- 默认画布：1080×1440（3:4）。
- 外边距约 42–48px；页内主内容区保持呼吸感但不留 >14% 无信息空白。
- 顶栏：左系列名 / 页序，右青绿胶囊徽章。
- 页脚：顶部分隔细线；左一句主题路径，右 `N / N` 页码。
- 有边框白卡高度贴合内容；禁止用 `space-between` / `margin-top: auto` 把框内撑出中空。

## 色彩与字体

| 角色 | 色值 |
|------|------|
| 纸面背景 | `#f7f7f5` |
| 白卡 | `#ffffff` |
| 主文字 | `#141414` |
| 次要文字 | `#5c5c5c` |
| 分隔线 | `#e6e6e2` |
| 软底 | `#f0f0ec` |
| 强调青绿 | `#1f6b5a` |
| 徽章浅底 | `#e8f3ef` |

- 字体：`PingFang SC` / `Microsoft YaHei` / `Noto Sans SC`；链接可用等宽。
- **封面主标题**：88–100px，超粗，尽量 1 行、最多 2 行；关键词可用青绿。
- **内页标题**：76–84px，最多 2 行。
- 条目名：34–40px 粗体；字段标签约 20–22px 青绿；正文约 22–24px，行高 1.34–1.42。
- 顶栏 / 页脚：约 20px。

## 通用页面骨架

### 封面

1. 顶栏 + 胶囊徽章  
2. 可选黑色小踢栏（如 `LEARNING PATH`）  
3. 超大封面标题（醒目优先）  
4. 一句导语说明本页/本辑在讲什么  
5. 下方 1–2 张白卡（清单、项目、要点），每卡可含：序号、标题、数据徽章、标签字段、链接条  

### 内页

1. 顶栏 + 徽章  
2. 大标题 + 一句副标题  
3. 并列白卡堆叠（常见每页 2 项；数量由材料决定）  
4. 页脚路径句 + 页码  

### 字段白卡（常见结构，可增删）

不强制字段名；材料有什么写什么。常见标签例如：简介 / 能学到 / 优势 / 适合 / 仓库。

```
[序号]  标题
        ★ 数据或副标
标签    正文……
标签    正文……
[等宽链接条或次要信息条]
```

## 文字排版

- 大标题尽量 1 行；过长最多 2 行，禁止 3 行。
- **封面标题 ≥88px；内页标题 ≥76px**；空间不够先缩短措辞或折行，禁止压到下限以下。
- 字段用两列网格（标签列约 78–92px + 正文），标签与正文顶对齐。
- 链接、仓库地址、命令保持纯文本原样，放在软底圆角条内，可自动断行。

## 密度与验收

- 遵守 [image-generation.md](image-generation.md)：页脚间距、面板填充、框内中空、标题行数与字号下限。
- 内容偏少：优先放大标题、白卡内边距、正文行距，而不是留大块空区。
- 内容偏满：先收紧卡内 padding / 行距，再略减副标题；最后才征得用户同意删次要句。

## HTML 资源

使用 `../assets/clean-teal/card-generator.html` 作为通用 HTML 起点。文件含封面 + 内页示例骨架与完整 CSS 变量；按材料替换文案、增减白卡与字段，不要机械保留占位项目内容。

```powershell
node scripts/check_card_layout.mjs cards.html --min-footer-gap 24
node scripts/render_cards.mjs cards.html output-directory card
```
