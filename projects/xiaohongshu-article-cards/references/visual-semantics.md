# 视觉语义规范

用于**阶段 2：生成图片**。在结构已确认、开始制作页面时读取；不在阶段 1 拆分结构时使用。

只有当视觉结构能够表达材料中的真实关系时才使用。先判断信息关系，再选择表格、时间线、流程、层级、比较卡或普通文本模块。

## 选择结构

| 信息关系 | 优先形式 |
|---|---|
| 连续叙述或观点展开 | 标题、短段落、引用、配图 |
| 并列清单 | 对齐列表或独立模块 |
| 多对象比较 | 表格、并列卡片或统一字段模块 |
| 时间或步骤顺序 | 时间线、编号步骤或线性流程 |
| 层级与包含 | 树形、缩进或嵌套容器 |
| 一一映射 | 对齐网格、连线或编号配对 |
| 因果与依赖 | 有向关系图，并标注关系含义 |
| 循环或双向关系 | 双通道、闭环或明确的往返路径 |
| 数据分布与趋势 | 图表，并保留单位、口径和来源 |

材料没有明确关系时，不要为了“更像信息图”而添加箭头、连线或虚构分类。

## 关系表达

- 每个视觉关系都必须有可识别的关联对象和关系含义。
- 只有关系本身具有方向、顺序或因果时才使用箭头。
- 线条承载动作、条件、数量或数据时，在线条附近标注相应语义。
- 双向或循环关系分别呈现不同方向，不把多段含义堆在一根悬空线旁。
- 无向关系使用无箭头连线、共同容器或其他中性表达。

抽象表达示例：

```text
对象 A → 对象 B：动作或传递内容
条件 X → 结果 Y：影响关系
项目 01 ↔ 说明 01：一一映射
```

这些只是语法示例，不是要求每个任务都出现对象框或箭头。

## 归属与映射

- 每段辅助文字都通过容器、对齐、连线、编号或稳定邻近关系，明确绑定到它所解释的对象。
- 多段说明分别对应多个对象时，显式呈现一一对应关系，不放入无法判断归属的共享区域。
- 同一语义层级使用一致的视觉语法；可以错落排版，但不能破坏归属判断。
- 共享说明只用于确实共同适用的内容，并明确标示适用范围。

## 比较与并列

- 比较对象使用相同字段、顺序和视觉权重。
- 缺失字段应明确留空或注明“不适用”，不要偷偷省去不利信息。
- 并列模块不必强制连线；只有存在真实关系时才连接。

## 图标与插图

- 图标用于快速识别、提示类别或辅助解释。
- 内容不足时可以加入贴合主题的简笔图标，但不得虚构信息或替代关键文字。
- 同组图标保持一致的线宽、尺寸和复杂度。
- 无法解释内容的装饰图、随机人物和填充箭头应删除。

## 交付前检查

- 遮住标题后，仍能判断每段说明属于哪个对象或信息组。
- 所有箭头、连线、容器和对齐关系都有真实语义。
- 阅读顺序清楚，不需要依赖猜测完成映射。
- 图示没有改变源材料的顺序、因果、范围或比较口径。
- 不使用某种视觉结构时，页面依然可以通过标题与正文清楚表达内容。
